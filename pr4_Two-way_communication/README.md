# PR4: 양방향 통신 트랙터 ECU 시뮬레이터

고급 양방향 통신 기반 트랙터 엔진 제어 유닛 (ECU) 시뮬레이션 시스템

## 📋 개요
실시간 물리 엔진 시뮬레이션과 양방향 통신을 결합한 고급 트랙터 ECU 시스템입니다. 웹과 Wokwi 시뮬레이터 간의 실시간 데이터 동기화를 지원합니다.

## 🏗️ 시스템 구조
```
웹 대시보드 ↔ FastAPI 서버 ↔ Wokwi ESP32
    (제어)      (ECU 시뮬)     (물리 시뮬)
                ↓
            엔진 물리 연산
```

## 🔧 기능
- **실시간 엔진 시뮬레이션**: RPM, 속도, 온도 물리 연산
- **양방향 통신**: 웹 ↔ 서버 ↔ ESP32 실시간 동기화
- **듀얼 입력 모드**: 웹 제어 / Wokwi 하드웨어 제어
- **자동 온도 관리**: 엔진 온도 기반 팬 속도 자동 제어
- **과열 보호**: 100°C 이상시 자동 비상 정지
- **실시간 그래프**: RPM/온도 추이 실시간 시각화

## 🌐 API 엔드포인트

### 고급 ECU (main.py)
| 메소드 | 경로 | 설명 |
|--------|------|------|
| POST | `/tractor/sync` | Wokwi와 데이터 동기화 |
| GET | `/control/accel` | 액셀 페달 제어 |
| GET | `/control/input` | 입력 모드切换 (WEB/WOKWI) |
| GET | `/control/engine` | 엔진 시동/정지 |
| GET | `/control/reset` | 비상 정지 리셋 |
| GET | `/status` | 전체 시스템 상태 |
| GET | `/` | ECU 대시보드 |

### 기본 서버 (server.py)
| 메소드 | 경로 | 설명 |
|--------|------|------|
| POST | `/tractor/sync` | 트랙터 데이터 동기화 |
| GET | `/control/{command}` | 수동 제어 명령 |
| GET | `/status` | 시스템 상태 조회 |

## ⚙️ ECU 상태 관리
```python
state = {
    "is_running": False,        # 엔진 작동 상태
    "input_mode": "WEB",        # 입력 모드 (WEB/WOKWI)
    "accel_pos": 0,             # 액셀 페달 위치 (0-100)
    "rpm": 0,                   # 엔진 RPM
    "speed": 0,                 # 차량 속도
    "engine_temp": 25.0,        # 엔진 온도
    "fan_speed": 0,             # 쿨링팬 속도
    "emergency_stop": False,    # 비상 정지
    "overheat_timer": 0         # 과열 타이머
}
```

## 🎮 제어 모드

### WEB 모드
- 웹 대시보드에서 액셀 페달 제어
- 슬라이더로 0-100% 제어
- 엔진 시동/정지 버튼

### WOKWI 모드
- Wokwi 시뮬레이터의 가변저항으로 제어
- 하드웨어 입력 우선 적용
- 실제 하드웨어 시뮬레이션

## 🔬 엔진 물리 연산

### RPM 계산
```python
target_rpm = accel_pos * 25  # 0-2500 RPM
rpm += (target_rpm - rpm) * 0.2  # 부드러운 변화
```

### 온도 시뮬레이션
- **발열**: RPM 비례 (RPM/2500 * 0.5)
- **냉각**: 팬 속도 기반 (팬속도/255 * 0.3 + 0.05)
- **자동 팬 제어**: 50°C 이상 작동, 80°C 이상 풀가동

### 속도 계산
```python
speed = rpm * 0.04  # RPM을 km/h로 변환
```

## 🎨 대시보드 특징
- **터미널 스타일**: 녹색 텍스트 검은 배경
- **실시간 데이터**: 1초 간격 업데이트
- **듀얼 차트**: RPM과 온도 그래프
- **액셀 슬라이더**: 실시간 페달 제어
- **상태 표시**: 모든 ECU 파라미터 표시

## 🚨 안전 시스템
- **과열 보호**: 100°C 도달시 10초 후 자동 정지
- **비상 정지**: emergency_stop 플래그로 즉시 정지
- **온도 제한**: 최소 25°C 이하로 내려가지 않음

## 📊 그래프 데이터
- **히스토리 길이**: 최대 30개 데이터 포인트
- **실시간 갱신**: 1초마다 새로운 데이터 추가
- **자동 정리**: 오래된 데이터 자동 제거

## 🔄 통신 프로토콜
1. **Wokwi → 서버**: POST /tractor/sync (온도 데이터)
2. **서버 → Wokwi**: 팬 속도, 정지 명령 응답
3. **웹 → 서버**: GET 제어 명령
4. **서버 → 웹**: 실시간 상태 브로드캐스트
