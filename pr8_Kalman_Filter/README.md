# PR8: 칼만 필터 (Kalman Filter)

## 📋 프로젝트 개요

칼만 필터를 사용하여 센서 데이터의 노이즈를 제거하고 부드러운 데이터를 생성하는 프로젝트입니다. 실시간 시뮬레이션을 통해 칼만 필터의 동작 원리를 시각적으로 확인할 수 있습니다.

## 🔧 코드 분석

### 1. SimpleKalman 클래스 (`simpla_kalman_filter.py`)

```python
class SimpleKalman:
    def __init__(self):
        self.estimate = 0.0         # 최종 예측값 (필터링된 데이터)
        self.error_est = 1.0        # 예측 오차 (얼마나 예측을 신뢰하는지)
        self.error_meas = 0.5       # 센서 오차 (센서의 신뢰도)
        self.last_estimate = 0.0    # 이전 예측값
```

#### 핵심 메서드: `update(measurement)`

1. **칼만 이득 계산**
   ```python
   kalman_gain = self.error_est / (self.error_est + self.error_meas)
   ```
   - 예측과 측정 중 어느 쪽을 더 믿을지 결정하는 가중치
   - 0에 가까울수록 예측을, 1에 가까울수록 측정을 더 신뢰

2. **최종 예측값 업데이트**
   ```python
   self.estimate = self.last_estimate + kalman_gain * (measurement - self.last_estimate)
   ```
   - 이전 예측값과 현재 측정값의 가중 평균

3. **예측 오차 업데이트**
   ```python
   self.error_est = (1.0 - kalman_gain) * self.error_est
   ```
   - 다음 계산을 위한 오차 보정

## 📊 칼만 필터 수학적 원리

### 기본 공식

1. **칼만 이득 (Kalman Gain)**
   ```
   K = P_est / (P_est + R_meas)
   ```
   - `K`: 칼만 이득 (0 ≤ K ≤ 1)
   - `P_est`: 예측 오차 공분산
   - `R_meas`: 측정 오차 공분산

2. **상태 업데이트**
   ```
   x_est = x_prev + K × (z_meas - x_prev)
   ```
   - `x_est`: 현재 추정값
   - `x_prev`: 이전 추정값
   - `z_meas`: 현재 측정값

3. **오차 공분산 업데이트**
   ```
   P_est = (1 - K) × P_est
   ```
   - 다음 단계를 위한 오차 보정

### 직관적 이해

- **K ≈ 0**: 예측을 더 신뢰 (부드러운 필터링)
- **K ≈ 1**: 측정을 더 신뢰 (빠른 반응 but 노이즈 많음)
- **K = 0.5**: 예측과 측정을 동등하게 신뢰
