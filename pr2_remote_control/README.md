# PR2: 원격 LED 제어 시스템

웹 기반 원격 제어 대시보드를 통한 LED 실시간 제어 시스템

## 📋 개요
웹 인터페이스에서 LED를 원격으로 제어하고 실시간 상태를 모니터링하는 시스템입니다. ESP32가 서버의 상태를 주기적으로 조회하여 LED를 제어합니다.

## 🏗️ 시스템 구조
```
웹 대시보드 → FastAPI 서버 ← ESP32
    (제어)      (상태관리)    (실행)
```

## 🔧 기능
- **웹 기반 제어**: HTML/CSS/JavaScript 대시보드
- **실시간 상태 모니터링**: 1초 간격 상태 갱신
- **메모리 상태 저장**: LED 상태를 서버 메모리에 저장
- **양방향 통신**: 웹→서버→ESP32 제어 흐름
- **반응형 UI**: 호버 효과와 애니메이션

## 📁 파일 구조
```
pr2_remote_control/
├── app/
│   └── main.py              # FastAPI 서버
├── esp32_remote.ino         # ESP32 펌웨어
└── diagram.json            # 시스템 다이어그램
```

## 🚀 실행 방법

### 서버 실행
```bash
cd pr2_remote_control/app
pip install fastapi uvicorn
python main.py
```

### ESP32 설정
1. `esp32_remote.ino` 업로드
2. LED를 GPIO 2에 연결
3. ngrok URL을 실제 서버 주소로 변경

## 🌐 API 엔드포인트

| 메소드 | 경로 | 설명 |
|--------|------|------|
| GET | `/` | 웹 제어 대시보드 |
| POST | `/control` | LED 상태 변경 |
| GET | `/status` | 현재 LED 상태 조회 |
| GET | `/get-led` | ESP32용 상태 조회 |

## 📱 웹 인터페이스 기능
- **ON/OFF 버튼**: LED 제어 버튼
- **실시간 상태 표시**: 현재 LED 상태 텍스트
- **자동 갱신**: 1초마다 상태 새로고침
- **시각적 피드백**: 버튼 호버 효과

## 🔗 통신 흐름
1. **사용자**: 웹에서 ON/OFF 버튼 클릭
2. **서버**: POST /control 로 상태 변경 수신
3. **서버**: 메모리에 LED 상태 저장
4. **ESP32**: 1초마다 GET /get-led 로 상태 조회
5. **ESP32**: 수신된 상태로 LED 제어

## ⚙️ 설정
- **LED 핀**: GPIO 2
- **통신 주기**: 1초
- **서버 포트**: 8000
- **와이파이**: Wokwi-GUEST

## 🎨 UI 특징
- **카드 디자인**: 깔끔한 카드 레이아웃
- **색상 구분**: ON(빨간색), OFF(검은색)
- **애니메이션**: 버튼 호버 및 스케일 효과
- **반응형**: 다양한 화면 크기 지원

## 🔄 상태 관리
