📋 동작 순서

1

웹 대시보드에서 제어

사용자가 웹 인터페이스의 토글 스위치를 클릭하여 LED를 제어합니다.

2

서버로 요청 전송

JavaScript가 FastAPI 서버의 /control 엔드포인트로 POST 요청을 보냅니다. (1초 지연)

3

서버에서 상태 저장

FastAPI 서버가 요청을 받아 메모리에 LED 상태를 저장합니다.

4

ESP32 상태 조회

ESP32가 주기적으로(1초 간격) 서버의 /status 엔드포인트에서 LED 상태를 확인합니다.

5

하드웨어 실행

ESP32가 받은 명령에 따라 GPIO 핀을 HIGH/LOW로 설정하여 LED를 제어합니다.

6

상태 피드백

웹 대시보드에서 실시간으로 현재 LED 상태를 표시합니다.

✨ 주요 특징

🌐 웹 기반 제어

인터넷이 있는 어디서나 웹 브라우저로 접근 가능합니다.

⚡ 실시간 응답

1초 이내의 빠른 응답 시간으로 즉각적인 제어가 가능합니다.

📱 반응형 UI

모바일, 태블릿, PC 모두에서 최적화된 인터페이스를 제공합니다.

🔄 양방향 통신

웹 → 서버 → ESP32, 그리고 피드백 경로까지 완전한 양방향 통신입니다.

💾 상태 저장

서버 메모리에 LED 상태를 저장하여 ESP32 재시작 후에도 유지됩니다.
