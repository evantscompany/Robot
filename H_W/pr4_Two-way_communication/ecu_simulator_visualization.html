🤖 엔진 제어 로직

물리 엔진 시뮬레이션: RPM, 온도, 속도를 실시간으로 계산합니다.
온도 관리: RPM과 액셀 페달 값에 따라 자동으로 엔진 온도를 계산합니다.
팬 제어: 온도 > 80°C일 때 자동으로 냉각 팬을 켭니다.
과열 보호: 온도 > 100°C일 때 엔진을 자동으로 정지합니다.
연료 소비: RPM과 부하에 따라 실시간 연료 소비량을 계산합니다.
양방향 동기화: 웹 제어 ↔ 서버 ↔ ESP32 간 실시간 데이터 동기화입니다.

📋 시스템 동작 순서

1

웹에서 명령 입력

사용자가 웹 제어 패널에서 RPM이나 액셀 페달 값을 조정합니다.

2

서버로 전송

웹 클라이언트가 FastAPI 서버로 제어 명령을 POST로 전송합니다.

3

ECU 시뮬레이션

서버에서 물리 엔진 시뮬레이션을 수행하여 RPM, 온도, 속도 등을 계산합니다.

4

센서 데이터 생성

시뮬레이션 결과를 기반으로 ESP32에서 받을 센서 값을 생성합니다.

5

ESP32로 명령 전송

서버가 팬 제어, LED 제어 등의 실행 명령을 ESP32로 보냅니다.

6

하드웨어 실행

ESP32가 받은 명령에 따라 실제 하드웨어(팬, LED 등)를 제어합니다.

7

센서 데이터 수집

ESP32가 실제 센서(온도, RPM, 등)에서 데이터를 읽어옵니다.

8

서버로 피드백

센서 데이터를 서버로 전송하여 웹 대시보드를 업데이트합니다.

9

실시간 시각화

웹 대시보드에서 실시간으로 모든 상태를 표시합니다.

✨ 주요 기능

🔄 양방향 통신

웹 ↔ 서버 ↔ ESP32 간의 완전한 양방향 실시간 데이터 동기화입니다.

⚙️ 물리 시뮬레이션

실제 엔진 동작을 시뮬레이션하여 현실적인 데이터를 생성합니다.

🌡️ 온도 관리

자동 온도 계산 및 과열 방지 기능이 포함되어 있습니다.

🎮 실시간 제어

웹에서 RPM, 액셀 페달 등을 실시간으로 제어합니다.

📊 다중 센서

RPM, 온도, 속도, 연료 소비 등 여러 센서 데이터를 추적합니다.

🔔 자동 보호

과열 시 자동으로 엔진을 정지합니다.
