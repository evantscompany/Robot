📈 데이터 흐름 및 동작 원리

1

📡 센서 데이터 수집

DHT22 센서에서 온도와 습도 데이터를 1초 간격으로 읽어옵니다. 센서의 정확도는 ±2°C, ±5%입니다.

2

⚙️ ESP32 처리

읽은 데이터를 처리하고 LED 제어 로직을 실행합니다. 온도가 30°C를 초과하면 LED를 켭니다.

3

🌐 서버 전송

ESP32에서 수집한 데이터를 HTTP POST로 FastAPI 서버로 전송합니다. ngrok을 통해 인터넷 연결을 구현합니다.

4

💾 데이터베이스 저장

받은 데이터를 SQLite 데이터베이스에 타임스탬프와 함께 저장합니다. 시계열 분석에 활용됩니다.

5

📊 시각화

웹 대시보드에서 Chart.js를 이용해 실시간 그래프를 표시합니다. 사용자는 브라우저에서 실시간 모니터링이 가능합니다.

✨ 주요 기능

🎯 실시간 데이터 수집

DHT22 센서로부터 1초 간격으로 온습도 데이터를 수집합니다.

🔄 양방향 통신

ESP32에서 서버로 데이터 전송, 서버에서 LED 제어 명령을 받습니다.

💾 데이터 저장

모든 센서 데이터를 SQLite에 저장하여 나중에 분석할 수 있습니다.

🔔 자동 경고

온도가 30°C를 초과하면 자동으로 LED를 켜서 경고합니다.

📱 웹 대시보드

어디서나 접속 가능한 반응형 웹 인터페이스로 모니터링합니다.

⚡ 저전력 설계

IoT 기기에 최적화된 효율적인 전력 소비 설계입니다.
