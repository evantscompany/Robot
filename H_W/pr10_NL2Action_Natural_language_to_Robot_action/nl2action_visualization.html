💬 자연어 명령 입력

💡 자주 사용되는 명령

→ 팬을 켜줘
→ 팬 꺼줘
→ 냉각 시스템을 시작해
→ 모든 액추에이터를 정지해

⚙️ AI 응답 및 명령

📝 OpenAI 응답
명령을 입력하면 AI가 분석하여 응답을 표시합니다.
📡 MQTT 명령 (JSON)
{ "action": "IDLE", "timestamp": "waiting..." }
상태: 대기 중

🤖 로봇 상태 및 실행 명령

❄️ 냉각 팬
OFF
🚰 냉각액 펌프
OFF
💡 상태 LED
OFF
🔊 경고음
IDLE

🔄 자연어 처리 흐름

사용자 입력
→
OpenAI API
→
JSON 파싱
→
MQTT 발행
→
ESP32 실행
1
사용자 입력 수집
사용자가 자연어로 로봇 제어 명령을 입력합니다.
2
OpenAI 모델 호출
입력 텍스트를 OpenAI GPT-4o 모델로 전송하여 의도 분석을 요청합니다.
3
JSON 응답 생성
AI가 {"action": "FAN_ON"} 또는 {"action": "FAN_OFF"} 형태의 JSON을 반환합니다.
4
JSON 파싱 및 검증
응답에서 JSON 객체를 추출하고 유효성을 검사합니다.
5
MQTT 토픽에 발행
명령을 MQTT 브로커(broker.hivemq.com)의 agri_log/robot/control/msm03 토픽으로 발행합니다.
6
ESP32에서 수신
ESP32가 MQTT 토픽을 구독하고 있다가 명령을 수신합니다.
7
하드웨어 제어
ESP32가 수신한 명령에 따라 냉각 팬, 펌프 등의 액추에이터를 제어합니다.

📋 자연어 → 명령 매핑

사용자 입력 예시 AI 해석 JSON 명령 실행 동작
팬을 켜줘 팬 활성화 요청 {"action": "FAN_ON"} GPIO에서 팬 시작
팬 꺼줘 팬 비활성화 요청 {"action": "FAN_OFF"} GPIO에서 팬 정지
냉각 시작 냉각 시스템 활성화 {"action": "COOLING_ON"} 펌프 및 팬 모두 시작
모든 기능 정지 전체 시스템 종료 {"action": "STOP_ALL"} 모든 액추에이터 정지

✨ 주요 특징

🗣️ 자연어 이해

OpenAI의 고급 언어 모델로 사용자의 의도를 정확하게 파악합니다.

🔄 MQTT 연동

공개 MQTT 브로커를 통해 IoT 기기와 통신합니다.

📡 실시간 제어

명령 입력 후 즉시 로봇 제어가 실행됩니다.

🛡️ 안전한 API 관리

.env 파일을 통해 API 키를 안전하게 관리합니다.

⚡ JSON 기반 명령

표준화된 JSON 형식으로 구조화된 명령을 전송합니다.

🌍 멀티 토픽 지원

MQTT 토픽으로 여러 로봇을 동시에 제어할 수 있습니다.
