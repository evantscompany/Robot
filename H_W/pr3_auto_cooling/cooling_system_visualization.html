🤖 자동 제어 로직

온도 < 30°C: 팬 정지
30°C ≤ 온도 < 50°C: 팬 낮은 속도 (50%)
50°C ≤ 온도 < 70°C: 팬 중간 속도 (75%)
70°C ≤ 온도 < 80°C: 팬 최대 속도 (100%)
온도 ≥ 80°C: 자동 정지 + 경고음
서보모터: 온도에 비례하여 0°~180° 회전
밸브 개방도: 온도% ÷ 100 × 180°

📋 동작 흐름

1

온도 측정

ESP32의 ADC(아날로그-디지털 변환기)가 가변저항 값을 읽어 온도로 변환합니다. (0-4095 → 0-100°C)

2

LED 판단

온도가 80°C를 초과하면 경고 LED를 점등하고, 그렇지 않으면 소등합니다.

3

팬 속도 계산

온도에 따라 팬의 PWM(펄스 폭 변조) 값을 계산합니다. 온도가 높을수록 더 빠르게 회전합니다.

4

서보모터 제어

온도에 비례하여 서보모터를 회전시켜 냉각액 밸브의 개방도를 조절합니다.

5

데이터 전송

현재 온도, 팬 속도, 밸브 각도를 FastAPI 서버로 전송합니다.

6

데이터 저장

SQLite 데이터베이스에 타임스탐프와 함께 저장되어 나중에 분석할 수 있습니다.

7

실시간 시각화

웹 대시보드에서 그래프와 게이지로 실시간 상태를 표시합니다.

✨ 주요 기능

🌡️ 온도 측정

가변저항으로 시뮬레이션된 온도를 실시간으로 측정합니다.

⚡ 자동 냉각

온도에 따라 팬 속도를 자동으로 조절합니다.

🚰 밸브 제어

서보모터로 냉각액 분출량을 비례 제어합니다.

🔔 과열 경고

80°C 이상 시 LED 경고등을 켜고 자동으로 정지합니다.

💾 데이터 로깅

모든 센서 데이터를 SQLite에 저장합니다.

📊 실시간 그래프

웹 대시보드에서 온도 추이를 차트로 표시합니다.
