# PR3: 자동 냉각 팬 제어 시스템

온도 기반 자동 냉각 시스템 with 서보모터 밸브 제어

## 개요
엔진 온도를 실시간 모니터링하고 자동으로 냉각 팬과 서보모터 밸브를 제어하는 스마트 쿨링 시스템입니다. 과열 방지와 효율적인 온도 관리를 목표로 합니다.

## 시스템 구조
```
가변저항(온도센서) → ESP32 → FastAPI 서버 → 웹 대시보드
                      ↓           ↓
                  서보모터      SQLite DB
                      ↓
                  LED (경고등)
```

## 기능
- **온도 측정**: 가변저항으로 시뮬레이션된 온도 입력 (0-100°C)
- **자동 냉각**: 온도에 따른 팬 속도 자동 제어
- **서보모터 제어**: 온도 비례 밸브 개방도 조절 (0-180°)
- **과열 경고**: 80°C 이상시 LED 경고등 및 자동 정지
- **데이터 로깅**: SQLite DB에 온도/상태 기록
- **실시간 모니터링**: 차트와 프로그레스 바 시각화

```bash

```

### ESP32 설정
1. `esp32_auto_cooling_servoM.ino` 업로드
2. 가변저항: GPIO 4
3. LED: GPIO 2
4. 서보모터: GPIO 18

## API 엔드포인트

| 메소드 | 경로 | 설명 |
|--------|------|------|
| POST | `/update` | 온도 데이터 수신 |
| GET | `/command` | LED 제어 명령 조회 |
| GET | `/status` | 전체 시스템 상태 |
| GET | `/history` | 최근 10개 기록 |
| GET | `/` | 모니터링 대시보드 |

## 데이터베이스 스키마
```sql
CREATE TABLE temp_logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    timestamp TEXT,
    temp INTEGER,
    led_status TEXT
);
```

## 제어 로직

### 온도 구간별 제어
- **30°C 미만**: 팬 OFF, 밸브 0°
- **50-79°C**: 팬 50% (128), 밸브 비례 제어
- **80°C 이상**: 팬 100% (255), 밸브 최대 개방, LED ON

### 서보모터 각도 계산
```python
angle = max(0, min(180, (temp - 30) * 2.5))
# 30°C → 0°, 100°C → 175°
```

## 대시보드 기능
- **실시간 차트**: 엔진 온도 그래프 (1초 갱신)
- **밸브 개방도**: 프로그레스 바 시각화
- **경고 시스템**: 과열시 깜빡이는 경고 메시지
- **정비 이력**: 최근 10개 DB 기록 테이블

## 하드웨어 설정
- **가변저항**: ADC GPIO 4 (0-3.3V)
- **LED**: GPIO 2
- **서보모터**: PWM GPIO 18 (50Hz)
- **온도 범위**: 0-100°C (ADC 0-4095)

## 통신 프로토콜
1. **ESP32 → 서버**: 온도 데이터 POST (1초 간격)
2. **서버 → ESP32**: LED 제어 명령 GET
3. **데이터 저장**: 자동 DB 로깅

## 안전 기능
- **과열 보호**: 100°C 이상시 10초 후 자동 정지
- **긴급 정지**: emergency_stop 플래그
- **최소 온도 제한**: 25°C 이하로 내려가지 않음

## 모니터링 지표
- **엔진 온도**: 실시간 온도 및 추이
- **밸브 개방도**: 0-100% 퍼센트 표시
- **팬 속도**: 0/128/255 3단계 제어
- **시스템 상태**: 정상/경고 상태 표시

## 트러블슈팅
1. **서보모터 작동 안함**: GPIO 18 연결 및 전원 확인
2. **온도 읽기 오류**: 가변저항 ADC 설정 확인
3. **DB 저장 실패**: 파일 권한 및 경로 확인

## 캘리브레이션
- **온도 보정**: 가변저항 값과 실제 온도 매핑
- **서보 중앙값**: 90°에서 밸브 중립 위치 조정
- **팬 속도**: 실제 팬 성능에 맞춰 속도값 조정
