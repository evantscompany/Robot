# Robot FSM + 좌표 이동 시각화 HTML ```html Robot FSM Visual Simulator

🤖 Robot FSM

IDLE
명령 대기 상태
CALCULATING
목표 좌표 계산 중
MOVING
목표 지점으로 이동 중
COMPLETED
도착 완료
현재 상태: IDLE
현재 좌표: (100, 100)
목표 좌표: (-, -)
시스템 시작 : 현재 상태 [IDLE]

🖱 클릭해서 목표 좌표 지정

파란 원 = 목표 좌표
초록 원 = 로봇
회색 점선 = 이동 경로
``` 브라우저에서 실행하면: * 클릭한 좌표를 목표 지점으로 설정 * FSM 상태가 IDLE → CALCULATING → MOVING → COMPLETED 로 변화 * 로봇이 실제로 목표 좌표까지 이동 * 지나온 위치에 발자국(path) 생성 * 좌측 패널에서 상태 변화 및 로그 확인 가능
