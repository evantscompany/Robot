# PR5: CAN 통신 시뮬레이터

차량용 CAN(Controller Area Network) 통신 프로토콜 기초 시뮬레이션 시스템

## 개요
CAN 통신의 핵심 원리를 시뮬레이션으로 구현한 교육용 프로젝트입니다. 다중 장치 간의 효율적인 데이터 통신 방식을 시각적으로 이해할 수 있습니다.

## CAN 통신이란?

CAN(Controller Area Network)은 자동차 내부 여러 ECU(Electronic Control Unit)들이 데이터를 교환하는 **멀티-마스터 통신 프로토콜**입니다.

### 핵심 특징
- **멀티-마스터**: 모든 장치가 데이터를 송수신 가능
- **브로드캐스트**: 한 장치가 보내면 모든 장치가 수신
- **ID 필터링**: 각 장치는 필요한 데이터만 선택적으로 수신
- **우선순위**: ID 값이 낮을수록 높은 우선순위

## 시뮬레이션 구현 원리

### 1. CAN 버스 클래스
```python
class CANBus:
    def __init__(self):
        self.subscribers = []  # 연결된 모든 장치
    
    def broadcast(self, sender_name, can_id, data):
        # 모든 장치에게 데이터 방송 (보낸 장치 제외)
        for device in self.subscribers:
            if device.name != sender_name:
                device.receive(can_id, data)
```

### 2. CAN 장치 클래스
```python
class CANDevice:
    def __init__(self, name, interested_ids):
        self.name = name
        self.interested_ids = interested_ids  # 필터링할 ID 목록
    
    def receive(self, can_id, data):
        # 관심 있는 ID만 처리
        if can_id in self.interested_ids:
            process_data(data)
```

## CAN 통신의 장점

### 1. 효율성
- **단일 버스**: 여러 장치가 하나의 통신선 공유
- **브로드캐스트**: 한 번의 전송으로 모든 장치에 전달
- **필터링**: 불필요한 데이터는 하드웨어 레벨에서 제거

### 2. 신뢰성
- **우선순위**: 중요 데이터 먼저 전송
- **오류 검출**: 데이터 무결성 보장
- **실시간성**: 지연 없는 통신

### 3. 확장성
- **쉬운 추가**: 새 장치를 버스에 연결만 하면 됨
- **표준화**: 자동차 업계 표준 프로토콜
- **유연성**: 다양한 데이터 타입 지원
